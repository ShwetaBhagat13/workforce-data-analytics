# Workforce Data Analytics (End-to-End Excel Project)

## 📌 Project Overview

This project demonstrates an end-to-end workflow of transforming raw employee data into a clean, reliable, and analysis-ready dataset using Microsoft Excel.

The raw dataset contained multiple real-world data quality issues such as duplicate records, missing values, inconsistent formats, and logical errors. A structured approach was followed to identify, validate, and handle these issues based on defined business rules.

The final output includes a cleaned dataset, analytical insights, and an interactive dashboard designed to support data-driven decision-making.

---

## 🎯 Problem Statement

The dataset was intended for workforce analysis, including salary trends, performance evaluation, and employee distribution.

However, due to inconsistencies and data quality issues, direct analysis would have resulted in inaccurate insights. The goal of this project was to ensure data integrity before performing any analysis.

---

## 🛠️ Approach

### 🔹 Data Cleaning & Validation

- Identified duplicate employee records and handled them using a rule-based approach  
- Differentiated between exact duplicates and mismatched records  
- Ensured each employee ID is uniquely and correctly represented  
- Flagged unreliable records instead of directly deleting them  

---

### 🔹 Data Standardization

- Standardized categorical fields such as Gender, Work Mode, and Currency  
- Fixed inconsistent text formats and naming variations  
- Converted unstructured or inconsistent values into a uniform format  

---

### 🔹 Handling Missing & Incorrect Data

- Identified and flagged missing salary values  
- Corrected invalid entries such as negative experience and inconsistent month values  
- Ensured logical consistency across all relevant fields  

---

### 🔹 Business Rule Implementation

- Applied performance-based rules for bonus eligibility  
- Ensured consistency between salary, bonus, and performance data  
- Assigned work mode based on employee classification  
- Validated currency usage based on employee type  
- Calculated overtime cost based on role hierarchy  

---

### 🔹 Data Integrity Controls

- Implemented validation checks to prevent incorrect future inputs  
- Restricted fields to predefined acceptable values  
- Created exclusion logic to separate unreliable data from analysis  

---

### 🔹 Data Preparation for Analysis

- Built a final cleaned dataset excluding invalid and inconsistent records  
- Structured data for accurate aggregation and reporting  
- Ensured consistency and reliability across all fields  

---

## 📊 Analysis & Insights

Performed data analysis to understand:

- Workforce distribution across departments  
- Salary trends across roles and experience levels  
- Relationship between performance ratings and bonus allocation  
- Work mode distribution (Office, Remote, Hybrid)  
- Overtime workload and cost distribution  
- Department-wise contribution to overall salary  

---

## 📈 Dashboard

Developed an interactive Excel dashboard featuring:

- Key performance indicators (KPIs)  
- Salary and workforce distribution visuals  
- Performance and bonus analysis  
- Department and role-level insights  
- Interactive slicers for dynamic filtering  

The dashboard provides a clear and concise view of key insights, enabling quick and informed decision-making.
